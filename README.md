# 🛠️ MAIN - Mantenimientos Integrales

Bienvenido al repositorio oficial del sitio web de **MAIN (Mantenimientos Integrales)**. Este proyecto está diseñado y alojado en **GitHub Pages** para ofrecer una presentación digital profesional de nuestros servicios especializados en mantenimiento de edificios, instalaciones eléctricas y sanitización por ozono.

🔗 **Visita el sitio web en vivo:** [https://michael0605.github.io](https://michael0605.github.io)

---

## 🌟 Sobre Nosotros
En **MAIN** nos especializamos en garantizar la operatividad, seguridad y salubridad de espacios residenciales y comerciales. Combinamos experiencia técnica y soluciones eficientes para optimizar cada infraestructura.

---

## 🔧 Servicios Principales

*   🏢 **Mantenimiento de Edificios:** Gestión preventiva y correctiva, reparaciones generales y optimización de instalaciones.
*   ⚡ **Servicios Eléctricos:** Instalaciones, revisiones técnicas, diagnóstico de fallas y adecuaciones normativas.
*   💨 **Sanitización por Ozono:** Desinfección profunda y eliminación de patógenos en ambientes cerrados para espacios más seguros y saludables.

---

## 🚀 Tecnologías Utilizadas
Este sitio web está desarrollado con tecnologías web modernas y ligeras para garantizar una carga rápida y una excelente experiencia en dispositivos móviles y de escritorio:
*   **HTML5 / CSS3** (Estructura y diseño adaptable)
*   **JavaScript** (Interoperabilidad y dinamismo)
*   **GitHub Pages** (Alojamiento web continuo)
